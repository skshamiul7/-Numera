## ✨ About

**Numera** is a sleek, modern math toolkit built with **Django** and styled with **pure HTML/CSS** (no frameworks, no JavaScript libraries). It bundles **44 essential math tools** across **8 well-organized categories** — perfect for students, teachers, developers, and anyone who loves numbers.

Whether you need to check if a number is prime, convert between number systems, solve geometry problems, or just roll a dice — Numera has you covered.

---

## 🚀 Features

- 🧮 **44 math tools** — from basic arithmetic to advanced number theory
- 📂 **8 organized categories** — clean, easy navigation
- 🌗 **Dark / Light mode** — with persistent preference via `localStorage`
- 🔍 **Live search** — filter tools instantly by name
- 🕘 **Recently used tools** — quick access to your last 5 tools
- 📱 **Fully responsive** — optimized for desktop, tablet, and mobile
- 📂 **Category dropdowns** — organized navbar for quick access
- ⚡ **Fast & lightweight** — no JavaScript libraries, no CSS frameworks
- 🎨 **Modern UI** — gradients, smooth animations, card-based layout
